**DeviNote** is a RESTful API built for managing secure, shareable notes and tags between users. The project is designed under a **Clean and Modular Architecture**, prioritizing strict separation of concerns, strong static typing, and high maintainability.

---

## 📌 Requirements Traceability Matrix

### 🔹 Functional Requirements (FR)
| ID | Requirement | Code Implementation / Layer |
|---|---|---|
| **FR1** | User authentication via email and password. | `routers/auth.py` ➔ `services/auth_service.py` |
| **FR2** | Full Notes CRUD (Create, Read, Update, Delete). | `routers/notes.py` ➔ `services/note_service.py` |
| **FR3** | Association of one or multiple tags per note. | `models/tag.py` & `models/note_tag.py` (M:N) |
| **FR4** | Sharing notes or tags with other users. | `services/share_service.py` ➔ `repositories/share_repository.py` |
| **FR5** | Access control for protected routes via Guards/Middleware. | `api/dependencies.py` (`get_current_user`) |
| **FR6** | Data isolation: Users can only access and modify their own notes. | User ID filtering constraints in `repositories/` |

### 🔸 Non-Functional Requirements (NFR)
| ID | Requirement | Technical Solution |
|---|---|---|
| **NFR1** | Token-based Authentication & Authorization. | **JSON Web Tokens (JWT)** signed via HMAC-SHA256 (`PyJWT`). |
| **NFR2** | Secure credential hashing. | Password hashing powered by **Passlib (Bcrypt)**. |
| **NFR3** | Modular, scalable, and maintainable architecture. | Clear separation into layers (API, Domain, Persistence, Services). |
| **NFR4** | Automated interactive API documentation. | OpenAPI / Swagger UI auto-generated by **FastAPI**. |
| **NFR5** | Strong typing and schema validation. | **Pydantic v2** + **SQLModel** over **PostgreSQL**. |

## 🏗️ System Architecture

The project adheres to **Clean Architecture** principles, partitioning the application into concentric layers with a unidirectional dependency flow:

```
┌─────────────────────────────────────────────────────────┐
│                      API / Routers                      │  <- HTTP, Endpoints, Serialization
└────────────────────────────┬────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│                        Services                         │  <- Business Logic, Auth Rules
└────────────────────────────┬────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│                      Repositories                       │  <- SQLModel / SQLAlchemy Queries
└────────────────────────────┬────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│                    Domain / Models                      │  <- DB Entities & Pydantic v2 Schemas
└─────────────────────────────────────────────────────────┘
```

## 🛠️ Tech Stack

* **Web Framework:** [FastAPI](https://fastapi.tiangolo.com/) (Python 3.10+)
* **ORM & Data Mapping:** [SQLModel](https://sqlmodel.tiangolo.com/) + [SQLAlchemy](https://www.sqlalchemy.org/)
* **Data Validation:** [Pydantic v2](https://docs.pydantic.dev/latest/)
* **Database:** [PostgreSQL](https://www.postgresql.org/)
* **Authentication:** OAuth2 with Bearer Tokens ([PyJWT](https://pyjwt.readthedocs.io/))
* **Security:** [Passlib](https://passlib.readthedocs.io/) with Bcrypt algorithm

## 🚀 Local Installation & Deployment

### Prerequisites
* Python 3.10+
* PostgreSQL instance (Local or Docker container)

### 1. Clone the repository
```bash
git clone https://github.com/jluisvacan/devinote.git
cd devinote
```

### 2. Virtual Environment & Dependencies
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Environment Configuration
Create a `.env` file in the project root following the example template:
```env
PROJECT_NAME="DeviNote API"
DATABASE_URL="postgresql://user:password@localhost:5432/devinote_db"
SECRET_KEY="super-secret-key-change-this-in-production"
ALGORITHM="HS256"
ACCESS_TOKEN_EXPIRE_MINUTES=60
```

### 

### 4. Run Development Server
```bash
fastapi dev app/main.py
```
